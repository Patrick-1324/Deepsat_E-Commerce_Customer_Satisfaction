# DeepCSAT – E-Commerce Customer Satisfaction Prediction

DeepCSAT is a deep learning project that predicts **Customer Satisfaction (CSAT) scores from 1–5** using customer-support interaction data from an e-commerce platform.

## Project Highlights

- End-to-end data cleaning, preprocessing and feature engineering
- ANN-based multiclass CSAT prediction
- TF-IDF processing for customer remarks
- Categorical encoding and numerical scaling
- Model evaluation and business insights
- Local Flask deployment with constrained dropdown inputs
- Saved deployment artifacts for consistent inference

## Final Model Results

| Metric | Score |
|---|---:|
| Test Accuracy | 72.12% |
| Majority Baseline | 69.40% |
| Macro F1 | 0.2547 |
| Quadratic Kappa | 0.3546 |
| CSAT MAE | 0.6537 |
| Within ±1 CSAT | 84.95% |

## Run Locally

Create and activate a virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

Start the Flask app:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## Main Technologies

Python, TensorFlow/Keras, Pandas, NumPy, Scikit-learn, TF-IDF, Flask, HTML/CSS.

## Notes

The Flask application uses the same saved preprocessing pipeline and ANN artifacts generated by the notebook. Dropdown relationships such as **Category → Sub-category** and **Manager → Supervisor → Agent** are constrained using the training data to reduce invalid inputs.

This project was developed as an individual deep learning submission for e-commerce CSAT prediction.
